## Review Notes for App Store

### For Apple Reviewers
```
Thank you for reviewing CookTalk!

HOW TO TEST:
1. Sign in with Google/Apple (test accounts not required)
2. On home screen, tap "Start Cooking Assistant" 
3. Grant microphone permission when prompted
4. Speak naturally to the AI assistant (e.g., "What can I cook?")
5. Browse recipes and try voice commands

DEMO CREDENTIALS (if needed):
- Not required - app works with any Google/Apple account

FEATURES TO TEST:
- Voice-guided cooking sessions
- Recipe browsing and search
- Favorites and cooking history
- Profile and preferences
- Both light and dark mode

NOTES:
- App requires microphone for voice features
- Internet connection required
- Best tested on physical device

If you have any questions, please contact: support@cooktalk.ai
```

### For Google Play Reviewers
```
CookTalk is a voice-first cooking assistant.

Test Instructions:
1. Install and launch
2. Sign in with Google
3. Allow microphone permission
4. Try "Start Cooking Assistant"
5. Speak to the AI assistant

The app requires:
- Microphone access (core functionality)
- Internet connection
- Android 8.0+

Contact: support@cooktalk.ai for any questions
```
